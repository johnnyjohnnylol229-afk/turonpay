# TURONPAY Premium — веб-приложение для iPhone

## Что внутри
- `index.html` — само приложение.
- `manifest.webmanifest` — настройки установки на главный экран.
- `sw.js` — кэш оболочки для повторного открытия без сети после первого посещения.
- `icons/` — иконки приложения.

## Важно
Для установки через Safari сайт должен быть опубликован по HTTPS. Просто открыть `index.html` как локальный файл недостаточно для режима веб-приложения и Service Worker.

## Публикация бесплатно через GitHub Pages
1. На Windows распакуйте ZIP.
2. Войдите на GitHub и создайте новый публичный репозиторий, например `turonpay-demo`.
3. Загрузите в корень репозитория все файлы и папку `icons` из архива (не загружайте сам ZIP вместо файлов).
4. В репозитории откройте **Settings → Pages**.
5. В разделе Build and deployment выберите **Deploy from a branch**, branch `main`, folder `/ (root)`, нажмите **Save**.
6. Дождитесь появления опубликованной HTTPS-ссылки вида `https://ВАШ-ЛОГИН.github.io/turonpay-demo/`.
7. На iPhone откройте эту ссылку в Safari → кнопка «Поделиться» → «На экран Домой» → включите «Открывать как веб-приложение», если этот переключатель показан → «Добавить».

## Ограничения
TURONPAY — демонстрационный интерфейс. Баланс, карты, PIN и платежи не подключены к реальному банку; не вводите реальные банковские данные. Не используйте макет как доказательство наличия денег или как официальный банковский сервис.


## Обновление Signature Edition
- Имя владельца в интерфейсе заменено на Талгат.
- Добавлен QR-сканер: камера работает в браузерах с поддержкой `BarcodeDetector`; предусмотрен ручной ввод кода как резервный способ.
- Убрано масштабирование жестом pinch-to-zoom в установленном веб-приложении.
- Пути манифеста, иконок и service worker адаптированы для GitHub Pages в подпапке репозитория.
- Важно: QR-сканирование демонстрационное. Приложение не подтверждает и не выполняет реальные платежи.


## TURONPAY Wallet Pro — новые функции
- Три демонстрационные карты: Kapitalbank UZCARD (UZS), Tenge Bank HUMO (UZS), Ipoteka Bank VISA (USD). Макеты авторские и не являются официальными банковскими картами; номера и балансы вымышлены.
- Добавлен раздел аналитики: расходы по категориям, поступления и пример недельного графика.
- Уведомления показывают последние локальные операции.
- Добавлен прототип настройки биометрии через WebAuthn/платформенный аутентификатор. Для безопасной банковской аутентификации обязательна серверная проверка; текущая реализация демонстрационная и не защищает финансовые операции.
- QR-сканер поддерживает ручной ввод и чтение QR в браузерах с BarcodeDetector. Поддерживается демо payload JSON с полями merchant/name, amount, currency. Подтверждение меняет только локальный демонстрационный баланс; реальные платежи не выполняются.
- В GitHub Pages загружайте содержимое папки `TURONPAY_PWA` поверх старых файлов. После загрузки service worker обновится до v3; если показывается старая версия, закройте PWA и откройте сайт в Safari заново.
